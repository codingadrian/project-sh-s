Trú — a proposed dictionary

This is meant to become a dictionary of proposed, modernized Bruncájc vocabulary — new coinages for concepts the documented language (Shá's) has no attested word for, built the way languages actually grow words: by extending existing roots, compounding, reconstructing from proto-Chibchan cognates, or borrowing across the Chibchan family, rather than inventing freely.

No proposed entries have been published yet. The methodology for how they'll be built already exists — a documented decision procedure that tries each strategy in order of how well-attested it is, tags every proposal with a confidence level, and treats nothing as settled until a proposed community language council reviews it. What's missing is the actual proposal work itself, which hasn't started.

The plan is for every future entry here to carry an explicit status — for example ai_proposed_neologism, community_proposed, or council_approved — so it's always clear how settled a given word is, unlike the existing Shá's dictionary, which records attested, documented vocabulary.

Until that work exists, the real, documented dictionary is at Shá's — Dictionary.
