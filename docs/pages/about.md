# About Project Shá's

*Shá's* means "root" in Bruncájc — this project takes its name from that
word because it's meant as the root system the project draws from: the
linguists, missionaries, community members, and researchers whose scattered
work over the decades this project is built on.

## What this is

Project Shá's is focused on Bruncájc (Boruca), a Chibchan language of
southern Costa Rica today spoken fluently by only a small number of elders.
It covers two tracks:

- **Shá's** — the language as it has actually been documented and spoken:
  a reference grammar and dictionary built from primary sources (dictionaries,
  manuscripts, narrative texts, and community materials).
- **Trú** — a proposed, modernized form of the language: an attempt to work
  out what a deliberate revival of Bruncájc could look like, including new
  vocabulary for concepts the documented language has no word for.

## An experiment, not a substitute

This project is, first and foremost, **an experiment in what AI can and
can't usefully do for language revival work**. It was built with AI, and AI
is used throughout for the linguistic analysis behind it — organizing and
cross-referencing sources, drafting synthesis documents, and (for the Trú
track) working out a disciplined methodology for proposing new vocabulary.

That also means this project has real limits, and it's worth being direct
about them:

- **It is not a substitute for the language.** Bruncájc belongs to the
  Boruca community, its speakers, and its own institutions — not to this
  project or to AI-assisted synthesis of secondary sources.
- **It is not a substitute for the community's authority over its own
  language.** Anything proposed under the Trú track is exactly that — a
  proposal — and this project explicitly imagines a community language
  council, not an AI system, as the body with real authority to accept,
  reject, or revise it.
- **It can get things wrong.** AI-assisted synthesis of scanned, sometimes
  contradictory historical sources is genuinely useful for surfacing
  patterns and organizing material at a scale that would otherwise take a
  long time to work through by hand — but it also makes mistakes, and
  entries here are marked with their review status and sourcing so readers
  can judge that for themselves.

What this project is meant to offer instead is a case study: a fairly
detailed, publicly visible attempt to use AI for language documentation and
revival-strategy work, warts and all, that other people working on language
revival — for Bruncájc or any other language — might find useful to look at,
critique, or learn from.
