# About Project Shá's

*This page is a placeholder — a fuller description of the project is coming soon.*

Project Shá's gathers reference grammars, dictionaries, and source bibliographies for
the Chibchan language family, built using AI, with AI also assisting the linguistic
analysis behind it. It's made for speakers, students, and academics, in the belief
that this kind of work — and the use of artificial intelligence more broadly — can
help make linguistic information more accessible and support language revival.
