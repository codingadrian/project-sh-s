Paya is the first language to split from the rest of the family, before the Vótico/Ístmico/Magdalénico division — so it isn't nested under any of the other branches on this tree. A reference grammar hasn't been written yet. Sources are catalogued in sources/other_languages/, including Forster's (2011) SIL grammar.
