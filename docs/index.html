Project Shá's

Shá's means root in Boruca. This project takes its name from that word because it's meant as the root system this project draws from — the linguists, missionaries, community members, and researchers whose scattered work over the decades this project is built on.

Project Shá's was built using AI, and AI is also used here for linguistic analysis — helping organize, cross-reference, and make sense of sources across the Chibchan language family. It's built for speakers, students, and academics alike.

We believe this project, and the use of artificial intelligence more broadly, can help make linguistic information more accessible and support language revival efforts.
