Bruncájc (Boruca)

A Chibchan language of southern Costa Rica, today spoken fluently by only a handful of elders. This project documents Bruncájc as it has been recorded and spoken — and, separately, explores what a deliberate revival of the language could look like.

This project is an experiment in using AI for language revival work — it is not a substitute for the language, for its speakers, or for the community's own authority over it. It's offered as one way to study and test strategies for language revival, built and analyzed with AI assistance throughout. Read more about the project →
